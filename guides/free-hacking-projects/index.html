1Trick an AI into breaking its rules

Skill: prompt injection, the technique of making an AI system ignore its own instructions.

  • Open Lakera Agent Breaker, the successor to Lakera's Gandalf game. It presents fake AI applications that you are allowed to attack.
  • Read each app's goal, then try to make it reveal or do something it is instructed not to. Keep notes on which phrasings work and why.
  • Compare your notes with how real programs define AI vulnerabilities, for example Google's AI Vulnerability Reward Program rules.

2Hack a deliberately vulnerable web store

Skill: real web vulnerabilities, practiced on an application built to be attacked.

  • Install OWASP Juice Shop on your own computer, following the instructions in its official repository.
  • Your first challenge is to find the hidden score board. It tracks every challenge you solve.
  • Work through the beginner challenges, such as logging in as the administrator and viewing another user's basket.
  • If you get stuck, use the official companion book, Pwning OWASP Juice Shop.

3Run a honeypot that records real attackers

Skill: seeing how automated attacks behave. In a 2019 Sophos study, the first attack on a cloud honeypot arrived 52 seconds after it went online.

  • Create a free virtual machine using Oracle Cloud Always Free resources. Do not run a honeypot on your home network.
  • Install Cowrie, an SSH and Telnet honeypot, following the Cowrie documentation.
  • Leave it running for at least a day, then read its logs: the passwords attackers tried and the commands they typed.
  • Follow your cloud provider's terms of use, and shut the machine down when you are finished.

4Booby-trap your own files

Skill: detection. A canary token alerts you the moment someone opens or uses a decoy.

  • Go to canarytokens.org (free, by Thinkst) and create a token, such as a Word document, a set of fake AWS API keys or a credit card number.
  • Give it a tempting name, such as "passwords" or "salaries", and store it on your own laptop or cloud drive.
  • Open it once yourself to see the alert email you will receive if anyone else does.

5Edit a game's memory

Skill: memory scanning, the same idea analysts use to see what a program stores.

  • Download Cheat Engine from its official site only.
  • Complete its built-in tutorial first (see the Cheat Engine tutorials).
  • In an offline single-player game, search memory for a value such as your gold, change it in the game, and search again until one address remains. Then edit it.
  • Never use it on online games. Anti-cheat systems detect it and accounts get banned.

6Test how fast your passwords fall

Skill: understanding password strength from the attacker's side.

  • Install Hashcat. It uses your graphics card. See the Hashcat wiki for setup and example hashes.
  • Create hashes of test passwords that resemble your own habits, and of a long random passphrase.
  • Run Hashcat against them and compare how long each one survives.
  • Only crack hashes you created yourself. Use what you learn to switch to long, unique passphrases and a password manager.

7Inspect your own phone's traffic

Skill: seeing which servers your apps contact and what they send.

  • Install mitmproxy (see getting started) or HTTP Toolkit (see its Android guide).
  • Route your phone's traffic through it and install its certificate as described in the certificate documentation.
  • Open one app at a time and note every domain it contacts. Some apps use certificate pinning, so their traffic will not be readable.
  • Remove the certificate from your phone when you are finished.

8Watch real malware in a sandbox

Skill: malware behavior analysis, without risking your own computer.

  • Create a free account on ANY.RUN. The Community plan runs analyses in virtual machines in your browser.
  • Browse public analyses to watch real malware families run: the processes they start, the files they change and the servers they contact.
  • Free analyses are public. Never upload personal or work files, and never download samples to your own machine.

9Build a new-device alert for your Wi-Fi

Skill: basic networking and scripting.

  • Install Python and write a script that scans your own home network every few minutes, for example using Nmap host discovery.
  • Store the devices it has seen, and compare each new scan against that list.
  • When a new device appears, send a message to your Discord server using a webhook.
  • Scan only networks you own or manage.

10Play hacking wargames

Skill: the command line, through puzzles.

  • Start OverTheWire Bandit. Each level hides the password to the next on a Linux server, and you find it with terminal commands.
  • Join TryHackMe's Advent of Cyber 2026, which starts on 1 December with a new free challenge each day.
  • When you finish Bandit, continue with the other OverTheWire wargames.

Staying safe and legal

  • Only test what you own or have written permission to test. Practice targets such as Juice Shop and wargames exist so that you never need to test anyone else's systems.
  • Keep honeypots isolated in the cloud and switch them off when you are done.
  • Never run malware on your own devices. Use a sandbox such as ANY.RUN instead.
  • Download every tool only from the official site or repository linked in this guide.
